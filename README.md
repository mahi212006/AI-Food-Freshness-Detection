# AI Food Freshness Detection

## Overview

A Python-based machine learning project designed to classify food images based on their freshness.

## Objective

The project aims to apply Artificial Intelligence and Machine Learning techniques to automate food freshness classification from images.

## Technologies Used

- Python
- Machine Learning
- Image Processing
- NumPy

## Project Structure

- `app.py` – Main application
- `train_model.py` – Model training script
- `freshness_model.pkl` – Trained machine learning model

## How It Works

1. Food image data is prepared.
2. The machine learning model is trained using the dataset.
3. The trained model is saved.
4. The application loads the trained model.
5. The input image is classified based on freshness.

## Future Scope

The project can be extended to support multiple food categories, improved prediction accuracy, and real-time image-based detection.
